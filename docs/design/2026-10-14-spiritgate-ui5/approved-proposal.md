# 추가 UI5와 첫 내부 TestFlight 계약 정합성 설계

- 설계 ID: `SGD-UI5-TF-110-v1`; 상태: **사람 승인 대기, UI5·중앙 실행 코드 미시작**.
- 개발 후보: main `59a4e062f4e7256d98df66205e2dd12470c7dabc`; 중앙 main `d9ef49cee3a5479f34b6a4758a1741df79a96d33`. 최종 후보는 실제 검수 뒤 고정한다.
- [전체 출시 설계](../2026-10-12-global-pixel-launch/design.md)와 기존 첫 내부 TestFlight 순서 예외를 유지한다.

## 추가 범위가 필요한 이유

UI1~4 원문은 그대로 보존한다. UI4는 타이틀3회·제품 입력0회에서 환경 차단으로 종료했으며 전체 기능·UX는 통과하지 않았다. 원래 실제 시작 시각과180+30분 한도를 다시 설정하거나 UI5를UI4로 이름 바꾸지 않는다.

기존 공식 Godot4.7.2와 별도 임시 counter에서 QA-only 접근성 설정을 적용하고 창을 활성화했다. 접근성 입력1회·실제 좌표 입력2회와 원래360×640 창의 count3을 확인했다. 이는 환경 진단이고 제품 검수 근거가 아니다. Editor Run 입력 경로 확인을 마친 뒤 추가 회차를 시작한다.

중앙 첫 내부 검증기는 실제 Editor 기록4개를 명시적으로 요구한다. 추가UI5의 실제 이력을 보존하려면 검토된 grant가 승인 회차 수5를 결속하도록 최소 보정이 필요하다. 단순히 기록4개로 줄이거나 차단 원본을 숨기지 않는다.

## 승인 요청 범위·시간·비용

- UI5 **한 회차**를 작성자/root와 다른 독립 검수자1명으로 실행한다.
- 첫 실제 제품 Run부터 본 검수180분, 발견 문제 재확인1회 최대30분, 전체210분 상한을 고정한다. 환경 장애와 대기는 같은 실제 시계로 기록하며 무제한 재시도·시작 시각 초기화·UI6은 하지 않는다.
- 28개 기능의 기능 판정과 UX를 각각 기록한다. 작은270×480·기준360×640·긴360×800과7언어의 실제 표시 크기를 측정한다. 저장·원본은 별도 격리하고 SHA·설정 지문·기능 목록·계획·검수자·실행 시각·입력·PNG/상태·로그를 결속한다.
- 준비 실패/재시도·저장 보존·언어cold restart·튜토리얼·5영웅8방향/스킬·8적/3보스·23웨이브/Endless·경제/유물/기록·모션/소리·일시정지/결과·긴문구/피격흔들림을 실제 UI로 확인한다. 조건을 준비하는 fixture와 실제 제품 입력/타격/보상 판정을 구분한다.
- Android 실제 기반4기능은 같은 후보의 인증·동의·실제 Test Ad·SSV/중복 방지 근거가 필요하다. Editor mock을 native 통과로 쓰지 않는다. iPhone만 기존 승인대로 내부 설치 이후 확인하며 면제하지 않는다.
- 비용: 추가 independent agent1명과 같은 기기/엔진 사용. 추가 구매·PixelLab 생성·AVD·새 인증서/프로필/bundle은 없다. 상한 초과·새 제품 결함으로 부족한 경우 미완료로 기록하고 추가 회차를 실행하지 않는다.

## 중앙의 최소 보정

- grant schema에 승인된 실제 UI 회차 수를4 또는5로 명시한다. 검증기는 이 값과 실제 iteration 수가 정확히 같아야 한다. 무제한 `>=4`로 열지 않는다.
-5를 선택하면 추가UI5 직접 사람 승인 원문·제안·시간 상한·후보 결속과 불변 중앙 hash 검토를 필수로 요구한다. 최초168시간 예외 기한을 연장하지 않는다.
- 마지막 회차와 전체 Editor E2E는 실제 기능/UX 통과를 요구한다. UI1~4의 failed/partial/blocked 원문과 원본 자산 hash를 보존하며 해결 근거는 실제 새 검수로 연결한다.
- 최초 내부 한 후보·한 빌드·한 업로드·INTERNAL_ONLY, 기존 profile/인증서 exact bytes·Apple live source/workflow/build 검증, Android 기반 기능, 정상 공개 검증을 유지한다. iPhone 외 deferred는 허용하지 않는다.
- 의미 있는 거절 검사를 먼저 실패시키고 최소 보정·전체 중앙 검사·패키징 검사를 통과시킨다. 새 한국어 Ready PR에서 검토한다. 현재 grantRegistry는 비어 있고 활성화하지 않는다.
- 새 보정 PR의 제한된 Claude 읽기 전용 코드 diff 리뷰는 별도 승인을 받은 범위에서만 진행한다. 도구는 모두 끄고 자격증명·PixelLab 원본·개인정보·실행 로그를 제외한다. 자동 Copilot을 포함해 총 요청2회를 넘지 않는다. 기존PR247·250에 추가 리뷰를 요청하지 않는다.
