# UI6 환경 복구와 누락 화면 검수 제안

상태: 승인 대기. UI6 실행·중앙 검증 변경·리뷰 전송은 아직 하지 않았다.

## 확인된 문제

UI5의 실제 실행은 2026-10-14 11:00:50.357Z부터13:24:27.903Z까지143.63분이었다. 7언어·3크기의 주요 화면을 관찰했지만 Tall EN 개인정보 화면 근거가 누락됐다. 창 설정/전면 전환 경로에서 Godot Editor ERROR가 났고, 승인된 단1회 재확인(231.453281초)에서도 해결되지 않았다. 해당 원문과 UI1~5 실패를 보존한다. QA 늦은 parent Tween 조건의 효과 외곽0.4563표시px 초과는 문장 누락과 구분하며 실제 Game 흔들림 경로를 확인해야 한다.

개발 정책은 새 UI3회 뒤 미해결이면 추가 회차·범위·시간을 승인받게 한다. 중앙의 현재 first-internal grant는4/5회만 수용하므로 새6회를 임의로 실행하거나 E2E를 UI6로 바꾸지 않는다.

## 제안 범위와 환경

- 별도 독립 검수자1명, UI6 본 검수180분, 발견 문제 재확인 단1회30분, 합산210분 상한. 첫 실제 실행 시작/종료를 고정하며 실패·잠금·중단도 시간에 포함한다.
- 원래 앱 소스 a7a9cdcdfe68f328b9775048f7451419d6623176과 제품 GDScript를 유지한다. 새로운 실제 코드 결함이 확인되어 소스를 고칠 경우 새SHA에서 검수와 중앙 결속을 다시 한다.
- 실행 전에 QA 복사본의 각 화면 크기 설정을 파일로 준비한다. 검수 중 Project Settings 창이나 single-window 대안을 반복 열지 않는다. 공식 Godot4.7.2/실제 Editor 실행·CUA 입력·격리 저장을 사용한다. 전역 Godot/보안/로그인 설정을 바꾸지 않는다.
- 28기능의 기능·UX,7언어×3크기의 주요 패널과 Tall EN 개인정보 화면을 빠짐없이 확인한다. 효과 경계는 실제 Game.add_shake와 production FloatingText를 사용하고 QA late-parent-Tween 조건은 별도로 표시한다.
- 모든 Godot ERROR는 실패이며 예외로 무시하지 않는다. Android 기반4는 별도 실제 근거를 연결하고 iPhone은 기존 첫 내부 설치 뒤 검수 시점만 유지한다. 둘 다 실제 면제하지 않는다.

## 중앙 최소 보정·리뷰
