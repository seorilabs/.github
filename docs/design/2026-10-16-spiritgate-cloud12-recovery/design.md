# Cloud12 계정 ID 보정과 단일 복구

승인 정본은 [동일 bytes 제안](approved-proposal.md)과 [직접 승인 기록](approval.json)이다. 제안의 “승인 전” 문구는 승인 요청 당시 상태이며 현재 실행 상태는 실행 기록을 따른다. 중앙 변경은 L1/dev/service-public, 앱 공개1.1.1의 L3·필수 실기기/전체 E2E는 유지한다.

실패12 FAILED/연결 빌드0/로그 hash → 명시 승인 확인 → 같은 후보13 한 회 → 실제 서명/before-deploy → 내부 VALID/그룹 → iPhone → 예외 제거 → 정상1.1.1 공개 순서다. 기본1회 한도는 유지하고 정확한 과거 실패가 승인된 경우만 총 Cloud2/업로드1을 허용한다.

제품 UI·세계관·저장·전투 데이터 변경은 해당 없음(중앙 릴리스 검증기만 변경). 새 Apple 리소스/비밀 변수 변경은 해당 없음(기존 자원 유지). 추가13 실패 시14 실행 없이 중단한다. 원래 만료와 실패 이력을 보존한다. 자세한 실패·대안·인수조건·운영·복구·리뷰 전송7파일 범위는 승인 정본에 있다.
