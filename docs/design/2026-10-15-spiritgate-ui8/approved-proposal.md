# UI8 한 회차와 중앙 최소 보정의 공개 범위 기록

이 문서는 승인된 비공개 설계의 동일한 실행 범위와 정지 조건을 공개용으로 옮긴 기록이다. 원래 설계 SHA256 `d6844c2a2afa8dd10a12cf27de6163d0cd9f1c6f41539bf24bb7d3cdfae2c715`와 이 파일의 SHA256은 구분한다. 원본 설계·승인·실제 관찰은 비공개 실행 원장에 그대로 보존한다. 승인 시각이나 권한을 새로 만들지 않는다. 후보는 `d031f54cde885aa5831ceb8c585dd42fba006fa3`다.

## 별도 입력 경로와 최초 진단

기존 공식 Godot4.7.2 완전한 앱의 별도 사본과 self-contained editor_data를 사용한다. 원본 실행 파일 SHA·완전한 앱 서명·템플릿·설정을 먼저 확인한다. 격리 설정에서 embed_on_play=false, QA 프로젝트에서 접근성 항상 켜짐을 선언해 Editor가 별도 일반 게임창을 실행하도록 한다. 전역 Godot 설정·macOS 접근권한·네트워크·로그인 보안 설정을 조작하지 않는다. 실제 자식 argv에 --embedded/--wid가 없고 일반 게임창·접근성 버튼이 존재함을 확인한다. 새 bundle ID·인증서·키·프로필은 만들지 않는다.

기존 소유 QA Editor는 경로·소유자를 확인하고 원본을 보존한 후 정상 종료한다. 새 진단/검수에서 만든 소유 프로세스는 정상 Stop 또는 소유 PID·경로를 확인한 SIGTERM1회로 종료한다. 입력이 중단되어도 종료·원본 보존은 허용하며 재실행 루프로 차단을 우회하지 않는다.

본180분 시계는 최초 진단 Editor 기동 직전부터 시작한다. 상태 없는 버튼 카운터/스크롤 진단 단1회·최대15분은 본180분 안에 포함한다. 세 크기에서 새 접근성 상태의 실제 버튼 클릭 총10회, 크기별 스크롤1회씩 총3회를 확인한다. 실제 게임·광고·저장·재화는 사용하지 않는다. 진단 실패나 새로운 권한/예상 밖 상태가 필요하면 기록·정상 종료하고 회차를 차단한다. 다른 앱/연결 경로/설정/진단 재시작을 연속 시도하지 않는다. 진단 통과는 제품 기능 통과가 아니다. 성공 후 제품 최초 Run과 저장/언어 검수에 계획된 정상 Stop→Run은 같은 본시계 안에서 수행한다. 입력 복구 목적의 재시작은 금지한다.

## 실제 UI8 범위와 시간

구현자와 다른 기존 독립 검수자1명이 L3의 전체28기능과7언어×3크기×8패널168영역을 실제 Godot Editor 실행으로 확인한다. 최초 진단을 포함한 본180분, 발견 문제 수정 후 단1회30분 재확인, 총210분이다. 잠금·오류·중단·캡처·판독·보고·정리를 모두 포함하고 과거 시간이나 미사용분을 이월하지 않는다. UI9·시간 연장·별도 진단 반복·유료 도구 구매를 포함하지 않는다.

실제 영웅5종의 이동/공격/스킬·적을 향하는 방향과 타격 시점, 적8종/보스3종, 저장/언어/동의/상점/성장/부활광고 취소와 결과 정지·터치 스크롤·소리/흔들림을 전부 확인한다. 자연 전투와 선언한 조건 fixture, 실제 UI 입력과 자동 검사·개발 Mock을 구분한다. 미실행·관찰만·파일 미수집·오류는 통과로 표시하지 않는다. 과거 후보의 부분 관찰을 새 후보 전체 실행으로 바꾸지 않는다.

새 QA 프로젝트·custom user dir·0바이트 locale/손상 fixture·4관찰/조건 helper·크기/로그/접근성/별도 창 설정을 Run 전 해시로 고정한다. 제품 GDScript·SDK·전투 수치·저장 식별자를 수정하지 않는다. 모든 PID/시각/source/config/로그 회전본을 결속하고, 매 Stop→다음 Run 사이 전체 로그·terminal 부분행을 원문 보존한다. 엔진 ERROR와 관찰 JSONL 부분행을 구분하고 원본은 비공개 근거로 둔다.

## 중앙 보정과 과거 실패

정상 v2의 기존 추가 승인 배열은8회차를 표현하므로 코드를 바꾸지 않는다. 첫 내부 v1 bootstrap만 approvedUiRounds=8·UI8 별도 승인·최종 후보/실제 설정·typed historicalUi7 검증을 추가한다. grant schema/runtime validator/회귀 검사와 필요한 provider 경계 검사·원장 설명만 대상이다. 기존4~7 조건과 원문·기한·서명·provider 제한을 유지한다.

UI7 원래 본 검수 후보와 실패/미완료를 iteration7에 남기고, 다른 수정 후보의 단일 부분 재확인은 별도 역사 필드로 source/config/두 시계/실패/미실행/파일 전환/실제 정상 종료를 보존한다. 원래180분/총210분과 intent 기준 더 이른30분 재확인 마감을 늘리지 않는다. 과거 부분 PASS들을 합산해 전체 PASS로 만들지 않는다. 마지막8만 현재 후보/실제 QA 설정에 결속한다. 잘못된 source/시각·승인 소급·회차 재번호·실패의 PASS 변경·원본 누락·시간 연장을 거절하는 검사를 포함한다. 실제 UI8/E2E/Android 근거가 모두 완성되기 전 registry는[]다.

새 한국어 Ready PR의 최종 코드 diff만 도구 없는 Claude Code 읽기 전용 리뷰로 전송한다. 자격증명·PixelLab 원본·개인정보·실행 로그·실제 원본 관찰자료는 제외한다. 자동 Copilot 포함 총 리뷰 요청2회가 상한이며 필수 검사·지적 처리·최종 HEAD/미해결 thread0 확인 뒤 병합한다. 권한·검증 하한·실패를 완화하지 않는다.

## 이어지는 출시와 정지 조건

실제 UI8 통과 → 같은 최종 SHA의 별도 전체 Editor E2E1회90분(UI8 종료 뒤 계획) → 같은 SHA의 Android 기반4/실제 Test Ad·Google SSV 확정·정확 지급·중복0 → 실제 근거/최종 설정의 별도 중앙 grant·버전번호 → 기존 프로덕션 서명의 한 후보/한 Cloud 빌드/한 업로드 → 처리 완료·내부1.1.0 TestFlight 실제 설치 순서다. 잘못된 프로필/인증서 산출물이면 한 빌드 실패로 중단한다.

원래 grant 만료 `2026-10-20T23:16:52.580641Z`와 v1 종료 `2026-10-22T00:00:00Z`를 늘리지 않는다. 첫 내부 완료 뒤 development_evidence.sh의 예외 인자를 제거한다. 공개1.1.1은 정상 v2·L3·양대 실기기 전체 회귀/E2E·7언어 마켓 자료·심사·승인·글로벌 공개·최종 국가 재조회·스토어 설치/업데이트 실제 실행까지 진행한다. 정상 v2 모바일 before-build/before-deploy는 개발 실행, before-release는 다른 에이전트의 실기기 실행까지 확인한다. 중국 본토·베트남·AppsInToss는 제외한다.

승인된 상한 안에 UI8나 별도 E2E 등이 미완료라면 내부/공개를 차단한다. 추가 회차·시간 연장·실기기/L3/별도 E2E/서명/마켓 공개 검증 면제는 없다. 임시 앱/editor_data/진단 프로젝트는 승인된 후속 E2E까지 끝나거나 실패 종료하면 필요한 원문/해시를 먼저 보존하고 자신이 만든 실행·캐시 사본만 정리한다. 원본 근거·QA 저장·사용자 설치/설정은 보존한다.
