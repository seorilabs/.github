# 계약 검증

실행 이슈는 [#315](https://github.com/seorilabs/.github/issues/315)다. 설계와 테스트 계획은 구현 전 `960d624`에 고정했다. 사용자의 추가 검수와 형식 수정 승인은 2026-10-30T07:06:54Z에 관측했다.

신규 합성 계약 테스트 40개를 구현 전에 실행했을 때 35개가 통과하고 유효한 새 입력 5개가 기존 스키마에서 거부됐다. 원본 red 로그를 보존했다. 필드를 추가한 뒤 관련 신규 및 기존 회귀 205개가 통과했다. 전체 검사에서는 조건부 스키마의 타입과 required 선언에 대한 strict compile 오류를 찾아 수정했다.

최종 전체 `npm test`는 1,918개 통과, 실패와 skip은 0개다. `npm run pack:check`, 기존 workflow 전체 actionlint와 `git diff --check`도 통과했다. 과거 회차는 현재 횟수에 넣지 않으며 SHA, 전체 범위, 유효기간과 사전 승인 조건의 거절 사례를 포함한다.

이 결과는 합성 입력을 사용한 CLI 계약 검사다. 실제 제품 UI, 기기, 마켓과 사용자 승인 실행으로 표시하지 않는다. Backoffice의 4~6회는 별도 실제 실행과 원본 보고서를 요구한다. 로컬 리뷰와 CI, 최종 NAS 보관 영수증은 연결 PR에 기록한다.
