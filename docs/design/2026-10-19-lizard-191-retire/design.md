# Lizard Tycoon 1.9.1 공개 연결 종료

사용자가 승인한 [공개 제안](https://github.com/seorilabs/lizard-tycoon/issues/805#issuecomment-6263609549)의 마지막 단계는 해당 후보의 중앙 예외 제거다. 제품 후보는 `da203979846fdcf4fb5b591689d776d84fe14911`, Google Play `v1.9.1`, versionCode `1001004042`다.

이 정리 준비 단계에서 프로덕션 승격과 제출36은 실행됐으며 심사는 검토 중이었다. 이 정리 변경은 미리 검토하고, Console의 출시와 한국 및 미국의 공개 버전 확인 뒤에만 병합한다. 심사 대기 중에는 main의 예외를 유지한다.

제거 대상은 1.9.1 grant, 전용 봉투 처리 분기, ZIP 조회 함수와 전용 테스트다. 정상 검증기를 1.9.1 예외 도입 전과 같은 내용으로 돌린다. 1.9.0의 internal/upload 한정 grant, 정상 v1과 v2 검증, 과거 QA 실패와 SHA, Release의 원본 ZIP 및 감사 문서는 보존한다.

검증은 L1 개발 환경으로 registry 제한의 red, 기존 검증 전체 회귀, 패키지 검사, PR CI와 교차 리뷰다. 새 제품 빌드, SDK 변경, 마켓 수정이나 기기 사용은 포함하지 않는다. 병합 뒤 원격 main에서 1.9.1의 전용 봉투가 승인 예외로 더 이상 통과하지 않는지도 확인한다.
