# 과거 부분 중단을 숨기지 않고 새 후보 검수로 이어간다

관련 이슈 #300. 승인 근거와 범위는 [설계](design.md), 실행 계획은 [test-plan.json](test-plan.json)을 따른다. 사용자 응답은2026-10-22T00:20:30Z에 확인했다. 앱 폰트 수정과 독립12~14,기기와 마켓 실행은 이 중앙 작업과 구분한다.

- HI-01: 원래 hash,failed/blocked,실제 부분 범위,알려진 SHA와 시각,당시 독립성을 필수로 보존한다.
- HI-02: 과거 완전과 중단의 합친 순서,실제 사전 승인과 상한 및 실패 해결을 검사하고 현재 합격 수는0회다.
- HI-03: 현재 후보의 완전한 독립 전체 기능 최소3회,마지막 통과,같은 SHA,168시간,새 사전 승인 및 플랫폼/출시 하한을 유지한다.
- HI-04: 기존 v2와 v1 의미를 유지하며 요구 red→green,관련 회귀와 전체 검사,package,actionlint,diff,독립 코드 검토와 로컬 리뷰 및 PR CI를 완료한다.

완료는 중앙 코드와 검사 및 정상 PR 병합으로 기록한다. 앱의 실제 실행,빌드,업로드,기기 QA와 공개를 이 작업에서 완료로 표시하지 않는다.
