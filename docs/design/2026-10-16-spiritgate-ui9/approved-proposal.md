상태: 승인 전 가역 초안. 실제 UI9·E2E·Android 통과, grant 등록, 빌드는 아직 주장하지 않는다.

## 목적과 범위

현재 중앙 12b9a09의 첫 내부 v1 경로는 UI8까지만 받는다. 정상 v2는 UI9를 이미 표현하지만, 제품의 normal 업로드 경로에는 최종 embedded profile·leaf certificate·entitlements·실시간 provider·동일 Cloud build/tree 결속이 없다. 제품 d031을 유지하며 기존의 정확한 업로드 전 서명 검사를 보존하려면 bootstrap만 UI9까지 최소 확장하는 안이 적합하다. 정상 v2는 바꾸지 않는다.

변경은 CODE 3파일이다: grant schema의 UI9·typed historicalUi8, bootstrap verifier의 과거 UI8·현재 UI9·별도 인계 대조, 합성 회귀 검사. 미적용 patch SHA256은 `a226b0c56ad4f665931adc7f23bdacd4eeb00654d39ebc117b5e94fc12eb3e7f`이며 378줄 추가·17줄 삭제다. 제품·워크플로·서명·키·권한은 변경하지 않는다.
